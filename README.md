## 🛠️ Công Nghệ & Thư Viện Sử Dụng

* **HTML5:** Chuẩn Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`) tối ưu SEO và Accessibility.
* **CSS3:** External CSS (`style.css`), CSS Variables (`:root`), Flexbox, CSS Grid Responsive.
* **Animate.css:** Hiệu ứng chuyển động xuất hiện ban đầu cho Hero Section & CTA Button.
* **AOS (Animate On Scroll):** Hiệu ứng cuộn trang sinh động cho các Section nội dung, Feature Cards và Gallery.
* **AI Tools:** ChatGPT (OpenAI Codex) hỗ trợ sinh mã nguồn và hỗ trợ quy trình Vibe Coding.
